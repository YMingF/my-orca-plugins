# Markdown 查看与编辑

这里可以直接编辑 **粗体**、*斜体*、~~删除线~~和 `行内代码`。

## 列表与表格

- [x] Raw / 富文本模式切换
- [x] 一键复制完整 Markdown
- [ ] 继续编辑这份文档

| 项目 | 说明 |
| --- | --- |
| 富文本 | 直接编辑标题、段落和表格 |
| Raw | 查看并编辑 Markdown 源文 |

## 代码编辑

代码块支持语言选择、语法高亮和一键复制。

```javascript
const modes = ['Raw', '富文本']
console.log(`当前支持：${modes.join(' / ')}`)
```
